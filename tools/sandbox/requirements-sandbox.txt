# DasLab WS-C optional LIVE sandbox deps (DAS-1566, blocked — not built here).
# Kept OUT of core requirements.txt so the engine stays server-free (WS-A
# pattern, ADR-0033 TB-1 / check_no_dead_runtime). Absent by default: the
# LocalStubSandbox (tools/sandbox/local_stub.py) needs NONE of this and is
# fully importable/testable with nothing installed.
#
# DockerSandbox (tools/sandbox/docker_sandbox.py) drives the `docker` CLI via
# subprocess, so its real dependency is the Docker ENGINE (a system package),
# NOT a python package — which is why this file has no hard requirement.
# Install the engine on the host that actually runs the sandbox, e.g.:
#   sudo apt-get install -y docker-ce docker-ce-cli containerd.io
#   sudo usermod -aG docker "$USER"   # then re-login
# Set DASLAB_DOCKER_BIN=podman to drive a rootless podman instead.
#
# Optional python extras (NOT required — the driver uses the CLI):
# docker>=7.0          # python Docker SDK
# e2b>=0.17            # E2B hosted-sandbox SDK (alternative managed backend)
