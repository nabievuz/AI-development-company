8 · SWOT — DasLab v2.0, 2026-07 holati

💪 Strengths

  • Org-as-code yagona kombinatsiya: 32 agent (4 daraja, charterlar) + QONUN qonunlari + AADL 6-gate + RACI + hash-chain attestation — 22 tizimning birortasida to'liq to'plam yo'q.
  • Bu hujjat-teatr emas: ~69k satr ishlaydigan Python, 97 script, 198 test-fayl, ~50 CI validator, 100/100 all-or-nothing release-gate.
  • Xotira intizomi: ArcRift majburiy recall/store + loyiha izolyatsiyasi + durable runs (checkpoint, resume/fork).
  • Golden-evals: 32 rolning har biriga ≥3 deterministik vazifa (≥0.80) + anti-gaming probe — agent sifatini o'lchaydigan kamdan-kam tizim.
  • Claude Code ekotizimi tekin meros: MCP, skills, plugins — o'z tool-katalogi kerak emas.

⚠️ Weaknesses

  • Distribution = 0: ~0★, bitta foydalanuvchi, bus-factor 1.
  • Anthropic lock-in: runtime faqat Claude Code; narx/limit/breaking-change to'liq tashqarida hal bo'ladi.
  • Enterprise-qobiq yo'q: SSO, multi-user, UI, SLA, compliance sertifikat — hech biri yo'q.
  • Jangda sinalmagan qismlar: HEARTBEAT va DGO-X shadow'da; kill-drill sintetik dispatcherda; founder-gate'da audit topgan regex xato.
  • Eval chuqurligi minimal: 3 task/rol — statistik jihatdan yupqa.

🚀 Opportunities

  • Governance bo'shlig'i: Gartner — 2027 ga borib korxonalarning 40% agentlarni governance kamligidan qisqartiradi; "guardian agents" 2028 talab. Policy-as-code sotiladigan qatlamga aylanmoqda.
  • Agent Teams ustiga "governance plugin": Anthropic orkestratsiyani yutgani sari DasLab'ning gate/board/audit qatlami native'ga qo'shimcha sifatida qiymatliroq bo'ladi.
  • Org-as-code niche bo'shab qoldi: ChatDev kompaniya-metaforadan voz kechdi (v2 generic DAG), MetaGPT commercial pivot — doimiy-tashkilot pattern'ida raqobat kam.
  • Plugin/marketplace kanali: Claude Code plugins + Cowork orqali distribution muammosini hal qilish yo'li ochiq.

🌪️ Threats

  • Anthropic absorption: Agent Teams + routines + managed agents DasLab dispatch qatlamini bosqichma-bosqich yeydi (eng katta xavf).
  • Model iqtisodiyoti: opus×10 allokatsiya narx oshsa og'irlashadi.
  • Solo-maintainer charchashi: 69k satr + 5 policy + 32 charter'ni bir kishi ko'taradi.
  • Katta o'yinchining governance'ga kirishi: LangChain/CrewAI policy-qatlam chiqarsa, farq torayadi.
